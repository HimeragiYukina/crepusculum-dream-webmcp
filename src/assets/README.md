# Asset organization

- `site/`: competition-edition pixel identity and interface assets
- `research/`: a nonrepresentational, redacted publication preview
- `fluid-simulation/`: captured fluid-simulation demonstrations
- `mods/redacted/`: nonrepresentational competition-edition gallery mosaics
- `photography/display/`: optimized, author-owned images bundled with the website; full-resolution sources are intentionally omitted
- `fonts/`: self-hosted web fonts and generated font subsets
